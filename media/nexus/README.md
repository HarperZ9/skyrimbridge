# SkyrimBridge Nexus media

This directory contains promotional artwork for the SkyrimBridge Nexus Mods page.
The `*-no-text-v2.png` files are generated, abstract brand art: they are not
gameplay captures, Skyrim UI captures, or images of Kitsuune's plugins or their
behavior. They contain no baked-in title or feature text.

## Text-free v2 assets

| File | Dimensions | Intended use |
| --- | ---: | --- |
| `skyrimbridge-nexus-header-3200-no-text-v2.png` | 3200 x 1800 | Full-resolution page header source |
| `skyrimbridge-nexus-header-1600-no-text-v2.png` | 1600 x 900 | Page header upload |
| `skyrimbridge-nexus-thumbnail-1400-no-text-v2.png` | 1400 x 1400 | Square thumbnail/avatar source |

The older artwork and the Zentropy Runic font files remain available unchanged
for provenance and compatibility with existing page layouts.

## Publication requirements

- Apply the Nexus Mods **AI Media** tag whenever any generated asset is used.
- Do not submit these generated assets to the current **25th Anniversary Mod
  Drive**; generated media is prohibited for that event.
- Do not present abstract promotional art as evidence of a runtime feature.
  Runtime visual or interoperability claims require clearly labeled, real
  in-game or SkyrimBridge UI captures.
- Keep generated promotional media visually and descriptively separate from
  real captures so visitors can identify each at a glance.
